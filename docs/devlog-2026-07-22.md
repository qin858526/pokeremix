## 战斗机制新增

### src/game/engine/BattleEngine.ts
- **草系免疫粉尘**：草属性宝可梦免疫毒粉/麻痹粉/催眠粉（Gen 6+ 机制）
- **防尘特性免疫粉尘**：拥有防尘特性的宝可梦免疫粉尘类招式
- **恶作剧之心**：变化招式优先度 +1
- **恶作剧之心对恶系失效**：对恶系目标使用变化招式时无效（Gen 7+ 机制）
- 修复 bug：所有"使用了"事件的 `actionSide` 字段补齐（原来仅 2/4 有该字段，导致进攻/受击动画方向错乱）

## 特性触发 UI 动效

- 新增 `TurnEvent.triggerSource`/`triggerSide` 字段，区分特性事件与普通事件
- 特性触发不再走文字日志，改为侧滑通知：
  - 玩家侧特性 → 从左侧中央滑入
  - 敌方侧特性 → 从右侧中央滑入
  - 2 秒后自动消失
- 所有特性触发事件（入场/接触/免疫/回合末/状态免疫等）均已标记

## 战斗界面重构成 2D 正作视角

### 布局
- 左上：敌方 HP 状态栏（黄色倾斜卡片风格）
- 右上：敌方精灵（正面朝左）
- 左下：我方精灵（背面朝右，使用真实 back sprite）
- 右下：我方 HP 状态栏
- 中央：招式宣布消息
- 底部：左侧技能菜单 + 右侧战斗日志

### 背面精灵
- 从 PokeAPI 下载 386 张背面精灵图到 `public/sprites/back/`
- 玩家方直接使用背面图，不再用 CSS 翻转模拟
- 精灵自适应大小 `min(380px, 35vh)`

### HP 状态栏
- 黄色渐变背景 + 深金色边框 + `skewX(-6deg)` 倾斜
- 显示名称 + Lv.50 + 属性标签 + 特性名
- HP 条颜色：>50% 绿色、25-50% 黄色、<25% 红色
- HP 数字靠右显示在 HP 条内部

### 分阶段动画
1. "XX使用了XX！" 消息弹出 → 攻击方前冲（0.45s）
2. 防守方受击抖动 + 闪白（0.3s）
3. HP 条渐变更新（0.4s CSS transition）
4. 属性克制反馈文字（0.5s）
5. 倒下旋转缩小淡出（0.5s）
6. 敌方/我方前冲方向分离（`lunge-right`/`lunge-left`）
